# Portfolio — Hugo Vidal

Site personnel statique, conçu pour être publié directement avec GitHub Pages.

## Aperçu local

Ouvrir `index.html` dans un navigateur ou lancer un serveur local :

```bash
python -m http.server 8000
```

Le site sera disponible sur `http://localhost:8000`.

## Publication

Une fois les fichiers envoyés sur la branche `main`, GitHub Pages publie le site à l'adresse :

`https://hugovidal1.github.io`
